# 코인 매수 후보 스크리너 설계

**날짜:** 2026-04-23  
**페이지:** `/crypto`  
**추가 API 비용:** 없음 (기존 Supabase crypto_daily 데이터만 사용)

---

## 목표

크립토 페이지 방문자가 "지금 어떤 코인을 살까?"라는 질문에 바로 답을 얻을 수 있도록, 기존에 수집된 지표(RSI, 스마트머니, 가격 모멘텀, 트렌딩)를 종합 점수로 환산해 매수 후보 TOP 5를 자동 제시한다.

---

## 데이터 소스

모두 `crypto_daily` 최신 row에서 추출. 추가 쿼리 없음.

| 필드 | 위치 |
|------|------|
| RSI (4h / 1d / 1w) | `rsiHeatmap[].rsi1d` 등 |
| 스마트머니 순유입 | `smartMoney[].net_flow_24h_usd` |
| 24h / 7d 가격 변동 | `market.coins[].price_change_24h`, `price_change_7d` |
| 거래량 | `market.coins[].total_volume` |
| 트렌딩 여부 | `trending[].id` 와 coins id 매칭 |

코인 유니버스: RSI 데이터 또는 스마트머니 데이터에 등장하는 코인의 합집합. 어느 한쪽에만 있으면 없는 쪽 점수는 0으로 처리.

## 점수 알고리즘

### 종합 점수 (100점 만점 + 보너스 10점)

```
totalScore = rsiScore + smartMoneyScore + momentumScore + trendingBonus
```

#### RSI 점수 (0–40점)
| RSI 1d 값 | 점수 |
|-----------|------|
| < 30 (강한 과매도) | 40 |
| 30 – 40 | 25 |
| 40 – 50 | 10 |
| 50 – 70 | 0 |
| ≥ 70 (과매수) | -20 |
| RSI 데이터 없음 | 0 |

#### 스마트머니 점수 (−15 – 35점)
| net_flow_24h_usd | 점수 |
|------------------|------|
| > $1,000,000 | 35 |
| $100,000 – $1,000,000 | 20 |
| $0 – $100,000 (소폭 유입) | 10 |
| < $0 (유출) | -15 |
| 스마트머니 데이터 없음 | 0 |

#### 모멘텀 점수 (0–25점)
| 조건 | 점수 |
|------|------|
| 24h 하락 AND 7d 상승 (눌림목) | 25 |
| 24h 상승 AND 7d 상승 (추세 지속) | 15 |
| 24h 하락 AND 7d 하락 | 0 |
| 24h 상승 AND 7d 하락 (단기 반등) | 5 |

#### 트렌딩 보너스
| 조건 | 점수 |
|------|------|
| CoinGecko 트렌딩 등장 | +10 |

## 프리셋 필터

버튼 클릭 시 가중치 배율만 바꿔서 클라이언트에서 재정렬. 서버 재요청 없음.

| 프리셋 | RSI 배율 | 스마트머니 배율 | 모멘텀 배율 |
|--------|----------|----------------|------------|
| 종합 (기본) | 1.0 | 1.0 | 1.0 |
| RSI 기술적 | 2.0 | 0.5 | 0.8 |
| 스마트머니 | 0.5 | 2.5 | 0.8 |
| 모멘텀 | 0.8 | 0.8 | 2.0 |

트렌딩 보너스는 모든 프리셋에서 동일하게 적용.

## UI 구조

### 섹션 위치
크립토 페이지 최상단 (기존 시장 개요 섹션 위). 페이지 진입 시 가장 먼저 눈에 들어오게.

### 레이아웃
```
[섹션 헤더] 매수 후보 스크리너
[프리셋 탭] 종합 | RSI 기술적 | 스마트머니 | 모멘텀

[코인 카드 × 5] (가로 스크롤 또는 1열 리스트)
┌────────────────────────────────┐
│ #1  BTC  Bitcoin               │
│ 점수: ████████░░  73점          │
│ 🟢 RSI 과매도(28)               │
│ 🟢 고래 유입 +$2.1M             │
│ 🟡 눌림목 (-3.2% / +8.1%)      │
└────────────────────────────────┘

[면책 고지] 투자 추천이 아닙니다. 참고용 지표입니다.
```

### 신호 태그 색상
- 🟢 초록: 강한 매수 신호
- 🟡 노랑: 중립 / 보조 신호
- 🔴 빨강: 부정적 신호 (과매수, 고래 유출)

## 컴포넌트 구조

### `lib/cryptoScreener.ts`
- 순수 함수 모음, 서버/클라이언트 양쪽 사용 가능
- `scoreCoin(coin, weights): number` — 단일 코인 점수 계산
- `getTopCandidates(data, weights, n): ScoredCoin[]` — 상위 n개 반환
- `getSignalTags(coin): SignalTag[]` — 신호 태그 목록 반환
- `PRESETS: Record<PresetKey, Weights>` — 프리셋 가중치 상수

### `components/CoinScreenerSection.tsx`
- Client Component (프리셋 탭 상태 관리)
- props: `data: CryptoDaily` (서버에서 전달)
- 내부에서 `getTopCandidates` 호출, 프리셋 전환 시 재계산
- 카드 렌더링, 점수 게이지 바, 신호 태그

- 기존 `cryptoData` 를 `CoinScreenerSection` 에 추가로 전달
