## Claude가 뭔데?

Claude는 Anthropic이라는 AI 안전 연구 회사에서 만든 대화형 AI입니다. ChatGPT랑 비슷하지만, 몇 가지 차이가 있습니다.

가장 두드러지는 특징은 **긴 맥락 처리 능력**입니다. 한 번의 대화에서 약 15만 단어(책 한 권 분량)까지 한꺼번에 넣고 분석할 수 있습니다. 거기다 한국어 이해도가 꽤 좋고, 코딩이나 글쓰기 작업에서 특히 빛납니다.

무료로 시작할 수 있고, [claude.ai](https://claude.ai) 에서 바로 써볼 수 있습니다.

## 핵심 팁 1 — 구체적으로 말해야 제대로 된 답이 나온다

Claude한테 모호하게 말하면, 모호한 답이 돌아옵니다.

**❌ 이렇게 하면 안 됨:**

```text
블로그 글 써줘
```

**✅ 이렇게 하면 좋음:**

```text
Next.js 블로그를 처음 만들어보려는 초보 개발자를 대상으로,
파일 기반 라우팅이 무엇인지 설명하는 500자 내외의 블로그 글 써줘.
전문 용어는 최대한 쉽게 풀어서 써줘.
```

두 번째처럼 **대상, 주제, 분량, 톤**을 같이 알려주면 첫 번째 시도에서 원하는 결과가 나올 확률이 훨씬 높아집니다.

---

## 핵심 팁 2 — 역할을 줘라

Claude한테 "너는 ○○야" 하고 역할을 부여하면 답변의 깊이가 달라집니다.

```text
너는 10년 경력의 시니어 백엔드 개발자야.
내가 짠 아래 코드를 리뷰해줘. 성능 문제나 보안 취약점 위주로.

[코드 붙여넣기]
```

이렇게 하면 일반적인 코드 리뷰가 아니라, 경험 있는 개발자 시각에서 실질적인 피드백이 나옵니다.

역할 예시:
- "너는 영어 원어민이야. 아래 문장을 자연스러운 영어로 교정해줘."
- "너는 스타트업 마케터야. 이 기능의 소개 문구를 짧고 임팩트 있게 작성해줘."
- "너는 까다로운 면접관이야. 이 자기소개서에서 약점을 찾아줘."

---

## 핵심 팁 3 — 예시를 보여줘라

원하는 결과물의 스타일이 있다면, 직접 예시를 보여주는 게 말로 설명하는 것보다 훨씬 효과적입니다.

```text
아래처럼 간결하고 직접적인 스타일로 제품 소개 문구 3개 써줘.

예시:
"설치 5분. 이후는 알아서."
"코드 없이 자동화."

제품: 매일 아침 날씨를 슬랙으로 보내주는 앱
```

예시를 3~5개 정도 주면 Claude가 스타일을 정확히 잡아냅니다.

## 핵심 팁 4 — Projects 기능 활용하기

Claude Pro에는 **Projects**라는 기능이 있습니다. 특정 프로젝트에 관련된 문서, 코드, 배경 정보를 미리 등록해두면, 이후 대화마다 그 맥락을 기억합니다.

예를 들어:
- 진행 중인 프로젝트의 기획서 PDF를 올려두면
- "이 기획서 기준으로 DB 스키마 설계해줘" 같은 질문에 즉시 맥락 있는 답변이 나옵니다

매번 배경 설명을 반복하는 게 귀찮았다면, Projects가 그 문제를 해결해줍니다.

---

## 실전 활용 예시

### 코딩할 때

Claude는 코드 작성, 리뷰, 디버깅 모두 잘합니다. 코드를 그냥 붙여넣으면서 "뭐가 문제야?" 하면 에러 원인 찾아주고, "이거 TypeScript로 바꿔줘" 하면 바꿔줍니다.

특히 에러 메시지를 그대로 붙여넣으면서 "이게 왜 나는 거야?" 하면 원인과 해결책을 같이 알려줍니다. 스택오버플로우 뒤지는 것보다 빠릅니다.

```text
아래 에러가 계속 나오는데 왜 그런지, 어떻게 고쳐야 하는지 알려줘.

Error: Cannot read properties of undefined (reading 'map')

[코드 붙여넣기]
```

### 긴 문서 요약할 때

PDF나 긴 글을 통째로 붙여넣고 "핵심만 5줄로 요약해줘" 또는 "이 내용에서 내 상황에 맞는 부분만 추려줘" 하는 식으로 쓰면 됩니다.

회의록 정리, 계약서 핵심 조항 파악, 논문 요약 등에 유용합니다.

### 글 쓸 때

초안을 직접 쓰기 막막할 때, 구조만 잡아달라고 하면 됩니다.

```text
아래 주제로 블로그 글의 목차와 각 섹션의 핵심 내용을 잡아줘.
내가 직접 쓸 거니까 초안은 필요 없고 구조만 잡아줘.

주제: 레트로 게임기 입문 가이드
```

## Claude Code — 개발자라면 이것도

Claude AI 웹 말고, **Claude Code**라는 CLI 도구도 있습니다. 터미널에서 직접 돌리면서 코드베이스 전체를 분석하거나, 파일 수정, 테스트 실행까지 시킬 수 있습니다.

설치:
```bash
npm install -g @anthropic-ai/claude-code
```

실행:
```bash
claude
```

프로젝트 폴더에서 실행하면 Claude가 전체 코드 구조를 파악하고, "이 프로젝트에 댓글 기능 추가해줘" 같은 지시에 직접 파일을 만들고 수정합니다.

웹 인터페이스보다 훨씬 강력하고, 코딩에서 체감 차이가 큽니다. 다만 API 키가 필요하고, 사용한 만큼 비용이 청구됩니다.

## 자주 하는 실수

**1. 너무 짧게 말한다**
"이거 고쳐줘"처럼 짧게 말하면 Claude도 뭘 어떻게 고쳐야 할지 모릅니다. 배경 설명을 조금만 더 추가하면 결과가 확 달라집니다.

**2. 첫 번째 답변에서 멈춘다**
첫 답변이 마음에 안 들면 "더 간결하게", "예시 추가해줘", "다른 방향으로" 하고 이어서 요청하면 됩니다. 대화를 이어가면서 점점 원하는 결과로 다듬어가는 게 Claude를 잘 쓰는 방식입니다.

**3. 사실 확인을 안 한다**
Claude가 틀린 정보를 자신감 있게 말하는 경우가 있습니다. 특히 최신 정보나 구체적인 수치는 꼭 직접 확인하세요.
